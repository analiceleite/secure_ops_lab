Entrega 02 concluída · limites explícitos

  • Sessão: expiração aproximada de cinco minutos e bloqueio após retirada de grupo confirmados pela autora. Sem refresh ou promessa de revogação instantânea.
  • Navegador: saúde autorizada, MFA e atributos do cookie de sessão relatados. Não houve coleta de valores de cookies.
  • OIDC: audiência/issuer/assinatura/nonce/state, grupos e cookie adulterado testados no binário real em ambiente isolado.
  • Operação: logout, OTP após retomada, Keycloak indisponível e ciclo API parada → 502 → recuperação validados.
  • Regressão: 35 testes API + 10 estáticos + 12 verificações isoladas aprovados. Não equivale a auditoria de produção.
Como explicar o fluxo em uma entrevista
  1. O navegador entra pelo gateway, não diretamente pela API.
  2. O gateway inicia Authorization Code com PKCE no Keycloak. O client exige senha e TOTP nos novos logins da aplicação.
  3. O gateway valida emissor, assinatura, audiência e nonce; casos negativos foram exercitados com tokens de teste no mesmo binário, sem alterar o emissor principal.
  4. O grupo /secureops-operators decide a autorização. A visitante pode autenticar e, mesmo assim, receber 403.
  5. Requisições autorizadas seguem para api:3000 pela rede interna. A API não valida tokens e o gateway está configurado para não encaminhá-los.

Limites que fazem parte do desenho

HTTP local e start-dev são exceções aprovadas para contas fictícias; não há criptografia de transporte. A rede identity não é interna e não demonstra bloqueio de saída. Containers autorizados na rede service podem acessar a API diretamente. Host, administradores e daemon Docker pertencem à base de confiança.

Volumes não são backup. Esta implementação não é ZTNA completo nem configuração pronta para produção.

Fora da topologia implementada

Monitoramento: SPEC/PLAN 03 em rascunho inicial com Uptime Kuma; revisão para Zabbix pretendida, ainda sem implementação. Tratamento e persistência de incidentes: planejados, não implementados; impacto da troca de ferramenta precisa de especificação. Nenhuma integração externa ou IA em runtime.
